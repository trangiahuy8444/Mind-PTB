Kiểu Dữ Liệu & Bản Chất Ép Kiểu (Type Casting)

📊 1. Bốn Kiểu Dữ Liệu Nền Tảng Trong Python

Hàm kiểm tra: type(x)

Trong lập trình, mỗi loại dữ liệu có hình thái và cách máy tính xử lý hoàn toàn khác nhau. Python có 4 kiểu dữ liệu cơ bản quan trọng nhất mà mọi lập trình viên đều phải nằm lòng:

Số nguyên

int

Các số nguyên không có phần thập phân (dương, âm hoặc số 0).

x = 15
y = -8
z = 0
Số thực

float

Các số có dấu chấm thập phân (Floating-point numbers).

pi = 3.14
diem = 9.5
nhiet_do = -1.2
Chuỗi ký tự

str

Đoạn văn bản bất kỳ được bao bởi cặp dấu nháy kép hoặc đơn.

name = "Huy"
msg = 'MindX'
num = "100"
Logic đúng/sai

bool

Kiểu Boolean chỉ mang đúng một trong 2 giá trị: Đúng hoặc Sai.

is_pass = True
is_rain = False
(Chữ T, F viết hoa!)

🔄 2. Bản Chất Ép Kiểu Dữ Liệu (Type Casting)

Ép kiểu (Type Casting) là hành động ra lệnh cho Python chuyển đổi một giá trị từ kiểu dữ liệu này sang một kiểu dữ liệu khác.

❌ CẠM BẪY KHI KHÔNG ÉP KIỂU:

trap_input.py

Vì a và b mang kiểu chuỗi str, dấu cộng + trở thành toán tử nối chuỗi, ghép hai đoạn chữ dính liền vào nhau!

✅ GIẢI PHÁP: ÉP KIỂU TRỰC TIẾP int()

cast_input.py

Bằng cách bọc int(...) bên ngoài hàm input(), giá trị chữ người dùng nhập lập tức được biến thành số nguyên để tính toán toán học chính xác!

🛠️ Bảng các hàm ép kiểu thông dụng nhất:

Hàm ép kiểu Mục đích Ví dụ lệnh Kết quả
int(x) Ép về số nguyên int("25") • int(7.9) 25 • 7 (Lấy phần nguyên, bỏ phần thập phân!)
float(x) Ép về số thực float("3.14") • float(10) 3.14 • 10.0
str(x) Ép về chuỗi chữ str(100) • str(True) "100" • "True"
bool(x) Ép về True/False bool(1) • bool(0) • bool("") True • False • False
🚨
Cạm bẫy lỗi ValueError: Nếu em cố ép một chuỗi không phải dạng số sang int, ví dụ: int("mindx") hoặc int("abc"), chương trình sẽ báo lỗi ValueError: invalid literal for int() và dừng chạy ngay lập tức!
