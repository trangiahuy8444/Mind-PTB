## 🌟 Giới Thiệu Khóa Học

Hệ thống web học liệu tương tác (Interactive Web Labs) được xây dựng theo chuẩn giao diện hiện đại, đồng bộ và liên kết kiến thức sư phạm chặt chẽ dành cho học sinh khóa **Lập trình Python Cơ Bản (TT-C4K-PTB30)**.

Toàn bộ các buổi học đều được tích hợp công nghệ chạy Python trực tiếp trên trình duyệt (**Skulpt Python Engine**), bộ mô phỏng ô nhớ RAM trực quan, trình mô phỏng sơ đồ khối động (Flowchart Stepper) và hệ thống trắc nghiệm phản xạ có chấm điểm tự động kèm giải thích chi tiết.

```
[Buổi 1: Biến & Lệnh Nhập/Xuất]
            │
            ▼ (Giải mã vì sao input() luôn trả về chuỗi text)

            │
            ▼ (Biểu thức trả về True/False -> Dùng làm điều kiện rẽ nhánh đèn xanh/đỏ)

            │
            ▼ (Tổng hợp 4 trụ cột -> Chinh phục bài toán lũy tiến bậc thang ngoài thực tế)

            │

            │
            ▼ (Lặp khi chưa biết trước số lần: lặp theo điều kiện)

            │
            ▼ (Tổng hợp toàn bộ vòng lặp & rẽ nhánh giải bài toán thực tế)
```

## 📚 Danh Sách Các Buổi Học & Tính Năng Tương Tác

### 🏠 [Trang Chủ Cổng Học Tập (index.html)](index.html)
- Tổng quan khóa học, bản đồ lộ trình học tập và bảng điều hướng 1-click tới toàn bộ 13 buổi học.

### 📘 [Buổi 1: Làm Quen Python, print(), input() & Biến Số](LESSON%201/index.html)
- **Lý thuyết:** Lệnh `print()`, lệnh `input()`, biến số là chiếc hộp dán nhãn trong RAM, quy tắc đặt tên biến snake_case.
- **Tương tác:** Mô phỏng cấp phát ô nhớ RAM (Interactive RAM Allocator), trình chạy code Skulpt (bài toán hỏi tên tuổi và bảng cửu chương 98).
- **Trắc nghiệm:** 10 câu hỏi phản xạ nhanh có chấm điểm và giải thích.
- **Thực hành:** Thiệp giới thiệu cá nhân, bảng cửu chương tùy biến.

### 📗 [Buổi 2: Kiểu Dữ Liệu & Bản Chất Ép Kiểu (Type Casting)](LESSON%202/index.html)
- **Lý thuyết:** 4 kiểu dữ liệu kinh điển (`int`, `float`, `str`, `bool`), hàm `type()`, giải mã cạm bẫy nối chuỗi `"10" + "20" = "1020"`, lỗi `ValueError`.
- **Tương tác:** Bộ phân tích chuyển đổi kiểu dữ liệu đa năng (Type Inspector Lab), máy tính tuổi 10 năm nữa có mô phỏng biến đổi kiểu.
- **Trắc nghiệm:** 10 câu hỏi trắc nghiệm kiểm tra độ hiểu sâu về ép kiểu.
- **Thực hành:** Cỗ máy thời gian dự đoán tuổi, máy đổi ngoại tệ USD sang VNĐ.

### 📙 [Buổi 3: Sức Mạnh Toán Tử (Số Học, Quan Hệ, Logic)](LESSON%203/index.html)
- **Lý thuyết:** Toán tử số học (`//`, `%`, `**`), toán tử quan hệ (`==`, `!=`, `<`, `>`, `<=`, `>=`), cổng logic (`and`, `or`, `not`), thứ tự ưu tiên PEMDAS.
- **Tương tác:** Máy tính toán tử tương tác (Operator Expression Evaluator), trình chạy code chia đội hình và điểm trung bình.
- **Trắc nghiệm:** Trọn bộ **20 câu hỏi trắc nghiệm** chuẩn hóa từ `Bai3_Trắc Nghiệm Toán Tử.pdf`.
- **Thực hành:** 4 bài tập thực hành tại lớp (Lũy thừa diện tích/thể tích, chia đội hình, điểm TB, chẵn lẻ).

### 📕 [Buổi 4: Cấu Trúc Rẽ Nhánh (if - elif - else) & Sơ Đồ Khối](LESSON%204/index.html)
- **Lý thuyết:** Cú pháp `if`, `if-else`, `if-elif-else`, 4 ký hiệu sơ đồ khối Flowchart quốc tế, 3 lỗi cấm kỵ: quên `:`, lỗi thụt lề `IndentationError`, nhầm `=` với `==`.
- **Tương tác:** Trình mô phỏng sơ đồ khối động (Flowchart Stepper Simulator) sáng viền từng bước và đồng bộ với giải thích.
- **Trắc nghiệm:** Trọn bộ **20 câu hỏi trắc nghiệm Wayground** có hình ảnh mã code thực tế từ `Trac_nghiem_Python_Hoc_sinh.pdf`.
- **Thực hành:** Trọn bộ 10 bài toán rẽ nhánh kinh điển (có tiền đề bài toán tiền điện 2 bậc).

### 🎓 [Buổi 5: Dự Án EVN & Ôn Tập Tổng Hợp 4 Trụ Cột](LESSON%205/index.html)
- **Lý thuyết:** Rà soát 4 trụ cột, phân tích bản chất mô hình "xô nước bậc thang" EVN (5 bậc + 8% VAT).
- **Tương tác:** Phòng thí nghiệm Trace Code Flowchart & Bộ nhớ RAM cho 4 bài toán thực tế, công cụ tính tiền điện EVN trực quan.
- **Trắc nghiệm:** 8 câu hỏi phản xạ bẫy logic sâu.
- **Thực hành:** Bộ mã nguồn mẫu chuẩn `bai5_on_tap.py` và bài tập về nhà.

### 🔁 [Buổi 6: Vòng Lặp for & Hàm range()](LESSON%206/index.html)
- **Lý thuyết:** Cú pháp vòng lặp `for`, 3 cách viết `range()` (kể cả step âm), biến tích lũy (tổng, đếm, tích/giai thừa), duyệt từng ký tự chuỗi và các bẫy hụt 1 / dãy rỗng.
- **Tương tác:** Trình mô phỏng từng lượt lặp (For-Loop Tracer) trực quan hóa dãy `range()`, dòng code đang chạy, biến trong RAM và Code Lab chạy Python trực tiếp với Skulpt.
- **Trắc nghiệm:** 12 câu hỏi trắc nghiệm phản xạ kiểm tra `for`, `range()`, biến tích lũy và lỗi cú pháp.
- **Thực hành:** 6 bài tập thực hành từ bảng cửu chương bất kỳ, tổng 1→n, đếm số chẵn (`for` + `if`), giai thừa `n!`, tam giác sao đến tổng tiền điện cả năm (12 tháng).

### ♾️ [Buổi 7: Vòng Lặp Vô Hạn (while), break & continue](LESSON%207/index.html)
- **Lý thuyết:** Phân biệt `for` vs `while`, 3 mảnh ghép của `while`, sơ đồ khối vòng lặp vô hạn, từ khóa `break`/`continue`, `Ctrl + C`.
- **Tương tác:** While-Loop & Break/Continue Tracer (4 kịch bản), Mini Game Casino Đoán Số Bí Mật 1–50 và Skulpt Code Lab.
- **Trắc nghiệm:** 12 câu hỏi kiểm tra `while`, `break`, `continue` và bẫy lặp vô hạn.
- **Thực hành:** 5 bài tập (cộng dồn tới `0`, kiểm tra điểm `0..10`, ATM khóa sau 3 lần sai, đếm chữ số, game đoán số).

### 🏝️ [Buổi 8: Lập Trình Giải Quyết Vấn Đề — Dự Án "Sinh Tồn Trên Hoang Đảo"](LESSON%208/index.html)
- **Lý thuyết:** Quy trình 4 bước giải quyết bài toán lớn, dựng khung sườn (Skeleton Code), quản lý trạng thái game và kẹp biên giá trị.

- **Thực hành:** 4 bài tập dự án (Đổi giây `Giờ:Phút:Giây`, Máy bán nước tự động, Kéo–Búa–Bao 5 hiệp, Hoàn thiện game Hoang Đảo).

### 🚂 [Buổi 9: Kiểm Tra Vòng Lặp & Nhập Môn Danh Sách (List)](LESSON%209/index.html)
- **Lý thuyết:** Ôn tập Checkpoint 2 vòng lặp, định nghĩa `list`, quy tắc chỉ số dương `0..n-1` & chỉ số âm `-n..-1`, `len()`, `IndexError`, `in`/`not in`, 2 cách duyệt `for`.

- **Trắc nghiệm:** 12 câu hỏi về danh sách, chỉ số và duyệt List.
- **Thực hành:** 5 bài thực hành (danh sách lớp, thống kê chẵn lẻ, tìm `max`/`min` thủ công, thanh tra túi đồ, Checkpoint 2 mini).

### 🎒 [Buổi 10: Danh Sách & Thao Tác CRUD (Thêm, Xóa, Sửa)](LESSON%2010/index.html)
- **Lý thuyết:** Mô hình CRUD với `.append()`, `.insert()`, sửa `ds[i]`, `.remove()`, `.pop()`, `.sort()`, `.reverse()`, phòng lỗi `ValueError` và bẫy `None`.

- **Trắc nghiệm:** 12 câu hỏi về các phương thức biến đổi danh sách.
- **Thực hành:** 4 bài thực hành (nhập 5 môn học, xóa sạch phần tử trùng, chấm điểm bỏ min/max, Shop Trang Bị Minecraft).

- **Lý thuyết:** Tính bất biến (Immutable) của `str`, Slicing `s[start:stop:step]`, đảo ngược `[::-1]`, các phương thức `.strip()`, `.upper()`, `.lower()`, `.replace()`, `.split()`, `.join()`, `ord()` & `chr()`.
- **Tương tác:** String Slicer Visualizer, bộ thử phương thức nhanh, Phòng Mật Mã Caesar Cipher + Skulpt Code Lab.
- **Trắc nghiệm:** 12 câu hỏi cắt xâu và xử lý chuỗi.
- **Thực hành:** 4 bài thực hành (đếm từ & chuẩn hóa, kiểm tra đối xứng Palindrome, bộ lọc chat, Mật mã Caesar).

### 🪄 [Buổi 12: Hàm (Function) — Chia Nhỏ Công Việc](LESSON%2012/index.html)
- **Lý thuyết:** Triết lý DRY, cú pháp `def`, phân biệt định nghĩa hàm vs gọi hàm, thứ tự nhảy lệnh và mô hình hàm gọi hàm.
- **Tương tác:** Function Call Flow Visualizer với Call Stack trực quan + Skulpt Code Lab.
- **Trắc nghiệm:** 12 câu hỏi về định nghĩa, gọi hàm và luồng thực thi.
- **Thực hành:** 4 bài thực hành (hàm kẻ viền & tiêu đề, hình vuông sao, chào theo giờ, Bàn phím Macro Q/W/E/R).

### 🧃 [Buổi 13: Hàm Nâng Cao — Tham Số, Đối Số, return & Phạm Vi Biến](LESSON%2013/index.html)
- **Lý thuyết:** Tham số vs Đối số, tham số mặc định, thí nghiệm `print()` vs `return` (`NoneType`), hàm có sẵn (`abs`, `round`, `max`, `min`, `sum`), biến Cục bộ (Local) vs Toàn cục (Global).
- **Tương tác:** Scope & Return Visualizer (Phòng khách Global vs Balo Local) + Combat Engine Code Lab.
- **Trắc nghiệm:** 12 câu hỏi về `return`, tham số mặc định và phạm vi biến.
- **Thực hành:** 4 bài thực hành chuẩn bị Hackathon Buổi 14 (chẵn/lẻ trả về `bool`, xếp loại học lực, diện tích tham số mặc định, Boss Battle Engine).

   - Mở bất kỳ file `index.html` nào bằng trình duyệt web yêu thích (Google Chrome, Microsoft Edge, Safari, Firefox).
   - Không cần cài đặt bất kỳ máy chủ (server) hay phần mềm nào khác!

2. **Kích hoạt GitHub Pages (Online):**
   - Sau khi push lên GitHub, truy cập **Settings** &rarr; **Pages** của repository.
   - Chọn nhánh **main** và thư mục **/ (root)** rồi nhấn **Save**.
   - Toàn bộ trang web sẽ được phát hành miễn phí trên internet theo địa chỉ:  
     `https://trangiahuy8444.github.io/Mind-PTB/`
