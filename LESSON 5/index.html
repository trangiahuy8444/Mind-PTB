Trạm 1: Tổng quan kiến thức (00' - 15')

Bốn Trụ Cột Nền Tảng Của Lập Trình Python

Trước khi giải quyết các bài toán lớn, hãy củng cố thật chắc chắn bản chất của 4 thành tố cơ bản nhất:

1. Biến (Variables)

Hộp chứa dữ liệu trong RAM máy tính. Tạo biến bằng toán tử gán =.

  • Quy tắc: Viết thường cách nhau bởi gạch dưới (snake_case).
  • Không bắt đầu bằng số (ví dụ: 1a là sai).
  • Không trùng từ khóa (như if, class, def).

2. Kiểu Dữ Liệu

Quyết định biến chứa được loại thông tin nào và tính toán ra sao:

  • int: Số nguyên (ví dụ: -5, 0, 100).
  • float: Số thực dấu phẩy động (ví dụ: 6.5, 3.14).
  • str: Chuỗi ký tự đặt trong dấu nháy "Python".
  • bool: Đúng/Sai (True / False).

3. Toán Tử (Operators)

Công cụ để tính toán và so sánh các biểu thức:

  • Số học: +, -, *, / (chia thực), // (chia nguyên), % (chia dư).
  • So sánh: == (bằng), != (khác), >, <, >=, <=.
  • Logic: and (và), or (hoặc), not (phủ định).

4. Câu Điều Kiện

Cho phép chương trình rẽ nhánh dựa trên điều kiện Đúng hay Sai:

  • if: Rẽ một nhánh khi đúng.
  • if ... else: Rẽ 2 nhánh đối lập (hoặc cái này, hoặc cái kia).
  • if ... elif ... else: Rẽ nhiều nhánh liên tiếp theo thứ tự từ trên xuống dưới.

3 Cạm Bẫy Học Sinh Hay Mắc Nhất Cần Nhớ:

1. Quên ép kiểu khi dùng input(): input() luôn trả về kiểu str. Muốn tính toán số học bắt buộc phải ép kiểu: kwh = float(input()) hoặc n = int(input()).

2. Nhầm lẫn giữa = và ==: Dấu = là lệnh Gán giá trị, còn == mới là phép toán So sánh bằng (cho ra True hoặc False).

3. Lỗi thụt lề (IndentationError): Các câu lệnh thuộc khối if, elif, else phải được thụt vào đúng 4 khoảng trắng (hoặc 1 phím Tab).

Trạm 2: Ngôn ngữ hình ảnh thuật toán

Quy Chuẩn Ký Hiệu Sơ Đồ Khối (Flowchart)

Trước khi viết code, lập trình viên giỏi luôn vẽ sơ đồ khối để thấy rõ mọi ngã rẽ của dữ liệu:

Khối Bo Tròn (Terminal)

Xác định điểm mở đầu hoặc kết thúc của luồng chương trình.

Khối Hình Bình Hành (I/O)

Tương ứng lệnh input() (Nhập dữ liệu) hoặc print() (Xuất thông tin).

Khối Hình Thoi (Decision)

Kiểm tra điều kiện rẽ nhánh (cho ra 2 hướng: Đúng / True hoặc Sai / False).

Khối Hình Chữ Nhật (Process)

Khối xử lý tính toán, gán giá trị biểu thức cho biến.
