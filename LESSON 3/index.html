⚡ 1. Ba Nhóm Toán Tử Trụ Cột Trong Python

Toán tử (Operator) là các ký hiệu đặc biệt giúp máy tính thực hiện các phép biến đổi toán học hoặc thẩm định các chân lý đúng/sai:

Nhóm 1

Toán Tử Số Học

Thực hiện tính toán trên số:

  • + Cộng (5 + 3 = 8)
  • - Trừ (10 - 4 = 6)
  • * Nhân (4 * 5 = 20)
  • / Chia thực (7 / 2 = 3.5)
  • // Chia nguyên (20 // 6 = 3)
  • % Chia dư (17 % 5 = 2)
  • ** Lũy thừa (2 ** 3 = 8)
Nhóm 2

Toán Tử So Sánh

So sánh 2 vế → Ra True/False:

  • == So sánh bằng (5 == 5 → True)
  • != So sánh khác (4 != 3 → True)
  • > Lớn hơn (10 > 15 → False)
  • < Nhỏ hơn (3 < 9 → True)
  • >= Lớn hơn hoặc bằng (8 >= 8 → True)
  • <= Nhỏ hơn hoặc bằng
Nhóm 3

Toán Tử Logic

Kết hợp nhiều điều kiện lại:

  • and: Chỉ True khi CẢ HAI vế đều đúng.
  • or: Chỉ False khi CẢ HAI vế đều sai (đúng 1 vế là True).
  • not: Đảo ngược chân trị (not True → False).

🔍 2. Bộ Ba Phép Toán Đặc Thù Trong Lập Trình

// (Chia lấy nguyên)

Bỏ qua toàn bộ phần dư thập phân, chỉ giữ lại phần nguyên. Ví dụ chia 23 cái kẹo cho 5 bạn: mỗi bạn được 23 // 5 = 4 cái kẹo.

% (Chia lấy phần dư)

Lấy phần dư còn lại sau phép chia. Ứng dụng kinh điển: n % 2 == 0 dùng để kiểm tra số chẵn, n % 2 != 0 là số lẻ!

** (Phép tính lũy thừa)

Dùng để tính số mũ $a^b$. Trong toán ta viết $2^3$, trong Python viết là 2 ** 3 = 8. Diện tích hình vuông cạnh $a$ là a ** 2!

⚠️
Phân biệt sống còn giữa = và ==:
• x = 5: Toán tử GÁN giá trị 5 vào biến x.
• x == 5: Toán tử SO SÁNH xem giá trị của x có bằng 5 hay không (cho kết quả True hoặc False).
